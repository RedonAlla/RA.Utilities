The primary goal of this namespace is to enhance the developer experience by providing convenient "shortcut" and "setup" methods.
These extension methods reduce boilerplate code and simplify common API development tasks in ASP.NET Core.
They abstract away setup complexity and provide elegant shortcuts, guiding developers toward writing cleaner, more organized, and more maintainable API code.

The namespace contains several key classes, each serving a distinct purpose:

### 1. [HttpEndpointServiceCollectionExtensions](./HttpEndpointServiceCollectionExtensions.md)

This class is the engine behind your **Endpoint Registration** feature.
Its purpose is to declutter your `Program.cs` file by discovering and mapping API endpoints at compile time through the source generator shipped with the package.
This is a core pattern for implementing a clean Vertical Slice Architecture.

### 2. [ValidationExtensions](./ValidationExtensions.md)
This class is designed to improve the developer experience when applying validation to Minimal API endpoints.
It provides a more fluent and readable syntax for adding the [`ValidationEndpointFilter`](../ValidationEndpointFilter.md).

### 3. [MiddlewareExtensions](./MiddlewareExtensions.md)
This class is the single entry point for every middleware shipped with the package, pairing an `Add` (service registration) with a `Use` (pipeline registration) method for each:
- `AddRaExceptionHandling` / `UseRaExceptionHandling` — registers the [`GlobalExceptionHandler`](../GlobalExceptionHandler.mdx) and adds its middleware to the pipeline, ensuring every unhandled exception is logged and returned to the client as a structured error response.
- `AddDefaultHeadersMiddleware` / `UseDefaultHeadersMiddleware` — registers and configures the `DefaultHeadersMiddleware`; configure required headers via `DefaultHeadersOptions.RequiredHeaders`.
- `AddLoggingMiddleware` / `UseLoggingMiddleware` — registers and configures the `LoggingMiddleware` for structured HTTP request/response logging.
- `AddRequestContextLoggingMiddleware` / `UseRequestContextLoggingMiddleware` — registers and configures the `RequestContextLoggingMiddleware`, which enriches log entries with request-scoped context such as the correlation ID.
