The primary goal of this namespace is to enhance the developer experience by providing convenient "shortcut" and "setup" methods.
These extension methods reduce boilerplate code and simplify common API development tasks in ASP.NET Core.
They abstract away setup complexity and provide elegant shortcuts, guiding developers toward writing cleaner, more organized, and more maintainable API code.

The namespace contains several key classes, each serving a distinct purpose:

### 1. [EndpointExtensions](./EndpointExtensions.md)

This class is the engine behind your **Endpoint Registration** Helpers feature.
Its purpose is to declutter your `Program.cs` file by automating the discovery and mapping of API endpoints.
This is a core pattern for implementing a clean Vertical Slice Architecture.

### 2. [ValidationExtensions](./ValidationExtensions.md)
This class is designed to improve the developer experience when applying validation to Minimal API endpoints.
It provides a more fluent and readable syntax for adding the [`ValidationEndpointFilter`](../ValidationEndpointFilter.md).

### 3. [ExceptionHandlingExtensions](./ExceptionHandlingExtensions.md)
This class simplifies the setup of global exception handling.
It provides a convenient one-liner for registering the [`GlobalExceptionHandler`](../GlobalExceptionHandler.mdx) with the DI container and another for adding its middleware to the request pipeline,
ensuring every unhandled exception is logged and returned to the client as a structured error response.

### 4. [HttpLoggingExtensions](./LoggingMiddlewareExtensions.md)
This class provides extension methods for registering and configuring the logging middleware.
It pairs `AddLoggingMiddleware` (service registration) with `UseLoggingMiddleware` (pipeline registration) in a single, cohesive entry point.

### 5. [DefaultHeadersMiddlewareExtensions](./DefaultHeadersMiddlewareExtensions.md)
This class provides extension methods for registering and configuring the `DefaultHeadersMiddleware`.
It pairs `AddDefaultHeadersMiddleware` (service registration) with `UseDefaultHeadersMiddleware` (pipeline registration).
Configure required headers via `DefaultHeadersOptions.RequiredHeaders`.

### 6. [RequestContextLoggingMiddlewareExtensions](./RequestContextLoggingMiddlewareExtensions.md)
This class provides extension methods for registering and configuring the `RequestContextLoggingMiddleware`.
It pairs `AddRequestContextLoggingMiddleware` (service registration) with `UseRequestContextLoggingMiddleware` (pipeline registration).
The middleware enriches log entries with request-scoped context such as the correlation ID.
