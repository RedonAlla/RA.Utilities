The `RA.Utilities.Api.Options;` namespace contains configuration classes used to customize the behavior of the middlewares in this package. Each options class follows the ASP.NET Core Options pattern and is configured via the `Action<T>` delegate parameter on the corresponding `Add*` extension method.

## 🧩 Available Options Classes

- [**DefaultHeadersOptions**](./DefaultHeadersOptions) — Configures the required headers and path exclusion for the `DefaultHeadersMiddleware`.
- [**HttpLoggingOptions**](./HttpLoggingOptions) — Configures path exclusion, header redaction, body size limits, and the slow-call warning threshold for the `LoggingMiddleware`.
