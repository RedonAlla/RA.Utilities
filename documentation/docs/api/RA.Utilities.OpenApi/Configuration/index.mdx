The transformers are configured via `appsettings.json`.

Available settings are:

* `OpenApiInfoSettings` — used by the [`DocumentInfoTransformer`](../DocumentTransformers/DocumentInfoTransformer.md)
* `HeadersParameterSettings` — used by the [`HeadersParameterTransformer`](../DocumentTransformers/HeadersParameterTransformer.md)
