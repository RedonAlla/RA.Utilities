The `RA.Utilities.Integrations.Utilities` namespace contains the internal plumbing used by [`BaseHttpClient`](../BaseHttpClient) and the generated parameter code.

| Class | Purpose |
|---|---|
| [`QueryUtilities`](./QueryUtilities) | Builds URL-encoded query strings from `QueryParams` collections and query request models. |
| `JsonConverterUtilities` | (Internal) Serializes request bodies to JSON and deserializes responses with camel-case naming. |
