---
title: RA.Utilities.Integrations.Extensions
---

The primary "glue" for your entire `RA.Utilities.Integrations` package.
The classes in this namespace provide a set of **extension methods** that simplify and standardize the process of configuring, extending,
and using [`HttpClient`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient) and its related components.

They follow the popular "fluent API" pattern, allowing developers to chain method calls together in a readable and discoverable way.
Since v10.2.0 the methods are declared as **C# 14 extension members**, grouped into one class per receiver type.

## Let's break down the purpose of each class:

### 1. [`ServiceCollectionExtensions`](./ServiceCollectionExtensions.md)
This is the most critical class in the namespace.
It is the main entry point for setting up [`HttpClient`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient)
integrations within the .NET dependency injection container.

  * **`AddHttpClientIntegration(...)`**:
  This is the star of the show. It masterfully encapsulates the entire process of registering a typed
  [`HttpClient`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient).
  It binds configuration, validates it on startup, and sets up the client's base address and timeout, all in a single line of code.
  * **Handler registration**:
  [`AddScopedHttpMessageHandler<T>`](./ServiceCollectionExtensions.md#addscopedhttpmessagehandlert) and
  [`AddTransientHttpMessageHandler<T>`](./ServiceCollectionExtensions.md#addtransienthttpmessagehandlert) register
  [`DelegatingHandler`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.delegatinghandler)s in the DI container
  so they can be attached to typed clients.

### 2. [`HttpClientBuilderExtensions`](./HttpClientBuilderExtensions.md)
This class contains the pipeline methods that chain off `AddHttpClientIntegration(...)` and attach [`DelegatingHandler`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.delegatinghandler)s to a specific typed client:

  * [`AddLoggingHandler()`](./HttpClientBuilderExtensions.md#addlogginghandler) — attaches the [`LoggingHandler`](../DelegatingHandler/LoggingHandler.md) for structured request/response logging.
  * [`AddInternalHeadersForwardingHandler()`](./HttpClientBuilderExtensions.md#addinternalheadersforwardinghandler) — attaches the [`InternalHeadersForwardHandler`](../DelegatingHandler/InternalHeadersForwardHandler.md) for service-to-service header propagation.

### 3. [`HttpRequestOptionsExtensions`](./HttpRequestOptionsExtensions.md)
This class provides utility methods for working with [`HttpRequestOptions`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httprequestoptions),
which are typically used inside a [`DelegatingHandler`](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.delegatinghandler).

  * [`GetClientIpAddress()`](./HttpRequestOptionsExtensions.md#getclientipaddress):
  A useful utility for extracting the client's IP address from the request context, which is invaluable for logging and auditing purposes within a handler.
