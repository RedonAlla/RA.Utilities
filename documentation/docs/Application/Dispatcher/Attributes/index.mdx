```powershell
Namespace: RA.Utilities.Dispatcher.Attributes
```

The `RA.Utilities.Dispatcher.Attributes` namespace holds attributes consumed by the package's **source generator**. They are compile-time annotations: they change what the generator emits, and cost nothing at runtime.

Today it contains [`PipelineBehaviorOrderAttribute`](PipelineBehaviorOrderAttribute.md), which pins the position of an auto-registered closed behavior in its pipeline.
