Namespace: RA.Utilities.Dispatcher.Generated

The `RA.Utilities.Dispatcher.Generated` namespace holds the small runtime-side infrastructure that the package's **source generators** feed. You never call into these types directly — the generated module initializers and [`AddDispatcher()`](../Extensions/DispatcherServiceCollectionExtensions.md) use them:

* **[`HandlerRegistrations`](./HandlerRegistrations.md)**: The queue carrying the compile-time registrations of handlers and closed pipeline behaviors.
* **[`DispatcherRegistrations`](./DispatcherRegistrations.md)**: The queue carrying the registration of the generated `Dispatcher` (which itself is emitted into this namespace inside your own assembly).

See the [Auto Registration](../auto-registration) and [Generated Dispatcher](../generated-dispatcher) guides for how the queues are applied.
