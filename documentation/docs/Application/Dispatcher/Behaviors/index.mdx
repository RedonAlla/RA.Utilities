`RA.Utilities.Dispatcher.Behaviors` provides built-in `IPipelineBehavior` and `INotificationBehavior` implementations for common cross-cutting concerns.

:::note
Every built-in behavior is a **generic open type**, so the source generator does not auto-register it (`DSAG010`) — add it explicitly with `AddDecoration<TBehavior>()` on the request or notification dispatch. Explicit decorations compose in call order; see [`PipelineBehaviorOrderAttribute`](../Attributes/PipelineBehaviorOrderAttribute.md) for the ordering of auto-registered closed behaviors.
:::

## 📦 Request Pipeline Behaviors

| Behavior | Interface | Purpose |
|---|---|---|
| [`LoggingBehavior<TRequest>`](LoggingBehavior.md) | `IPipelineBehavior<TRequest>` | Logs each request and its result |
| [`LoggingBehavior<TRequest, TResponse>`](LoggingBehavior.md) | `IPipelineBehavior<TRequest, TResponse>` | Logs each request and its response |
| [`ValidationBehavior<TRequest>`](ValidationBehavior.md) | `IPipelineBehavior<TRequest>` | Validates requests via FluentValidation; returns a failed `Result` containing a `BadRequestException` on invalid requests |
| [`ValidationBehavior<TRequest, TResponse>`](ValidationBehavior.md) | `IPipelineBehavior<TRequest, TResponse>` | Validates requests via FluentValidation; returns a failed `Result` containing a `BadRequestException` on invalid requests |

## 📬 Notification Pipeline Behaviors

| Behavior | Interface | Purpose |
|---|---|---|
| [`NotificationLoggingBehavior<TNotification>`](NotificationLoggingBehavior.md) | `INotificationBehavior<TNotification>` | Logs notification handling start and finish |
| [`NotificationMetricsBehavior<TNotification>`](NotificationMetricsBehavior.md) | `INotificationBehavior<TNotification>` | Measures handler duration; warns if over 500 ms |
| [`NotificationRetryBehavior<TNotification>`](NotificationRetryBehavior.md) | `INotificationBehavior<TNotification>` | Retries failed handlers with configurable backoff |
