The classes within the `RA.Utilities.Feature.Abstractions` namespace define the core interfaces for the CQRS pattern and the custom mediator.

## ✨ Purpose and Function

These interfaces form the contract between the mediator, your requests/notifications, and their handlers. They are the foundation upon which the Vertical Slice Architecture is built.

The primary abstractions are:

* **[`IRequest` / `IRequest<TResponse>`](../Abstractions/IRequest.md)**: Marker interfaces for commands (no response) and queries (with response). Implement these on your request DTOs.
* **[`IRequestHandler<TRequest>` / `IRequestHandler<TRequest, TResponse>`](../Abstractions/IRequestHandler.md)**: Interfaces your handlers implement. For a more convenient experience with built-in logging and exception handling, inherit from the abstract [`RequestHandler`](../Handlers/RequestHandler.md) base classes in the [`Handlers`](../Handlers/index.mdx) namespace instead.
* **[`IPipelineBehavior<TRequest>` / `IPipelineBehavior<TRequest, TResponse>`](../Abstractions/IPipelineBehavior.md)**: Cross-cutting concerns that wrap request handler execution (validation, logging, etc.).
* **[`INotification`](../Abstractions/INotification.md)**: Marker interface for events/notifications in the publish/subscribe system.
* **[`INotificationHandler<TNotification>`](../Abstractions/INotificationHandler.md)**: Interface for notification subscribers.
* **[`INotificationBehavior<TNotification>`](../Abstractions/INotificationBehavior.md)**: Cross-cutting concerns that wrap notification handler execution (retry, metrics, logging).
* **[`IMediator`](../Abstractions/IMediator.md)**: The central dispatcher — sends requests and publishes notifications.
* **[`IFeatureBuilder`](../Builders/FeatureBuilder.md)**: Exposes the `IServiceCollection` from fluent builders.

## 🧠 Summary
In summary, the `RA.Utilities.Feature.Abstractions` interfaces are the cornerstone of the CQRS pattern in this framework. For concrete handler implementations, see the [`Handlers`](../Handlers/index.mdx) namespace which provides abstract base classes with automatic logging and exception handling.
