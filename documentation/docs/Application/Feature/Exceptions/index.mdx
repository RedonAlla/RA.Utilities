The `RA.Utilities.Feature.Exceptions` namespace contains the exception types specific to mediator dispatch. Failures from your **handlers and pipeline behaviors** should use the typed exception hierarchy from [`RA.Utilities.Core.Exceptions`](../../../core/RA.Utilities.Core.Exceptions/index.mdx) (`NotFoundException`, `ConflictException`, `BadRequestException`, ...) so that the API layer's `GlobalExceptionHandler` maps them to HTTP responses — the exceptions in this namespace are reserved for the mediator's own dispatch failures.

The primary type is:

* **[`HandlerNotFoundException`](./HandlerNotFoundException.md)**: Thrown when an object-based `Send`/`Publish` cannot be dispatched because the message's runtime type has no (or an ambiguous) handler contract.
