# Migration Guides

Use this page when upgrading `RA.Utilities.Core.ValueObjects` between versions that introduce breaking changes.

## Version 10.0.0 — Initial Stable Release

`10.0.0` is the first stable release of `RA.Utilities.Core.ValueObjects`, so there are no breaking changes to migrate from. If you are adopting the package for the first time, see the [Getting Started](./index.mdx#getting-started) guide and the [How-To Guides](./index.mdx#-how-to-guides).

:::info Release Notes
The full release notes for every version, including breaking-change callouts, live in the package's [releasenotes.md](https://www.nuget.org/packages/RA.Utilities.Core.ValueObjects) (bundled in the NuGet package).
:::

### Future migrations

When a new major or minor version introduces a breaking change, a step-by-step migration section will be added here, following the format used by the other RA.Utilities packages.
